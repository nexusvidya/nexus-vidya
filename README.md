# 🕉️ वैदिक ज्ञान CMS

ज्योतिष, वास्तु शास्त्र, वैदिक न्यूरोलॉजी, नेम न्यूमेरोलॉजी और करंट अफेयर्स के लिए पूर्ण कंटेंट मैनेजमेंट सिस्टम।

## फीचर्स

- ✅ कैटेगरी और **सब-कैटेगरी** बनाएँ
- ✅ पोस्ट/टॉपिक लिखें (HTML सपोर्ट)
- ✅ **फोटो और वीडियो** अपलोड
- ✅ फीचर्ड इमेज
- ✅ सर्च फंक्शन
- ✅ व्यू काउंटर
- ✅ एडमिन डैशबोर्ड
- ✅ हिंदी UI

## कैसे चलाएँ

### 1. Python इंस्टॉल होना चाहिए (3.8+)

### 2. डिपेंडेंसी इंस्टॉल करें

```bash
cd vedic-knowledge-cms
pip install -r requirements.txt
```

### 3. सर्वर शुरू करें

```bash
python app.py
```

### 4. ब्राउज़र में खोलें

- **वेबसाइट**: http://127.0.0.1:5000
- **एडमिन पैनल**: http://127.0.0.1:5000/admin/login

### लॉगिन डिटेल्स

| फील्ड     | वैल्यू     |
|-----------|------------|
| Username  | `admin`    |
| Password  | `admin123` |

> **सुरक्षा**: प्रोडक्शन में पासवर्ड ज़रूर बदलें!

## उपयोग कैसे करें

1. एडमिन में लॉगिन करें
2. **कैटेगरी** सेक्शन में नई कैटेगरी या सब-कैटेगरी बनाएँ
3. **नया पोस्ट** पर क्लिक करके लेख लिखें
4. फोटो/वीडियो अपलोड करें
5. प्रकाशित करें

## फाइल स्ट्रक्चर

```
vedic-knowledge-cms/
├── app.py                 # मुख्य एप्लिकेशन
├── requirements.txt
├── instance/
│   └── vedic.db           # SQLite डेटाबेस (ऑटो बनेगा)
├── static/
│   ├── css/
│   ├── js/
│   └── uploads/           # अपलोडेड फाइलें
└── templates/
    ├── admin/
    └── ...
```

## नोट

- अपलोड लिमिट: 100 MB प्रति फाइल
- सपोर्टेड इमेज: JPG, PNG, GIF, WEBP, SVG
- सपोर्टेड वीडियो: MP4, WEBM, MOV, AVI, MKV
- डेटाबेस और अपलोड्स `instance/` और `static/uploads/` में सेव होते हैं
